# Sys Semantic Soundness UX v0.1

The editor consumes a typed projection from Sys Platform. `SUPPORTED_EXACT`, `UNSUPPORTED`, and `UNRESOLVED` are preserved as separate dispositions; parsed text and confirmed human intent never promote an item to governed.

Fixture mode supplies deterministic F1-F6 examples. Live mode is contract-driven and must expose `PLATFORM_API_GAP` when the structured soundness fields are absent; it never substitutes fixture data. Views only render the read model.

The current adapter remains fixture-backed until the platform `WorkspaceSnapshotV1` soundness fields land. The future adapter can populate `SysSemanticItem`, `SysRecoveredMeaning`, and `SysSyncItem` without changing the view boundary.
